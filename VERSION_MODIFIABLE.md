# Version modifiable — ANGE HMG HOME

Le fichier `ANGE_HMG_HOME_Dossier_de_Marque_Modifiable.pptx` est la version PowerPoint entièrement modifiable du dossier de marque.

## Pour modifier le dossier

1. Ouvrir le fichier dans **Microsoft PowerPoint**.
2. Cliquer sur un texte pour modifier les mots, la taille ou la couleur.
3. Cliquer sur une image pour la remplacer ou recadrer la photo.
4. Cliquer sur une forme (fond, ligne, encadré) pour changer ses couleurs ou dimensions.
5. Exporter en PDF depuis PowerPoint : **Fichier → Exporter → Créer un document PDF/XPS**.

Le fichier peut aussi être importé dans **Google Slides** ou **Canva**. Pour conserver au mieux la mise en page, PowerPoint est recommandé.

## Recréer le fichier après une modification des sources

```bash
npm run build:portfolio-editable
```

Les éléments de la présentation sont volontairement séparés : textes, photos, couleurs et formes restent individuels et modifiables.
